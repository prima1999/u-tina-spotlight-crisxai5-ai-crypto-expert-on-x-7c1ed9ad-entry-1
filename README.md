Spotlight @crisxai5: a must-follow AI and crypto expert on X — AI agents, crypto insights, and Web3 innovation, explained in plain words. This entry's program copies POST.json (the address of the public X post) to /output; the post text lives in POST-TEXT.md and the spotlight image in spotlight.png.

## Run it

```sh
node main.ts
```

It copies `POST.json` to `/output/POST.json`. Pass a different output directory as the first argument to write there instead.
